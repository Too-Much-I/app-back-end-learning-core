# 파트별 학습 — 콘텐츠 제공 시에만 이용권 확인 보완 R1

- 날짜: 2026-10-23
- revision: `lc-billing-part-learning-content-only-amendment-r1`
- 상태: 사용자 정책 변경 승인 반영. Billing 보완 수락·제품 구현·실행 검증·배포는 미완료.
- 기준: [review-2 원문](LC-BILLING-PART-LEARNING-ELIGIBILITY-RECOMMENDATION-R1.md), [기존 구현 기준 확인](LC-BILLING-PART-LEARNING-ELIGIBILITY-ACCEPTANCE-R1.md).

## 1. 승인 범위

사용자는 이용권 없이 직접 채점 API를 호출할 수 있는 잔여 위험을 확인한 뒤 콘텐츠 제공 시에만 검사하는 방향을 승인했다. 정상 학습 중 이용권 만료·환불·Billing 장애 때문에 제출이 중단되지 않도록 한다.

| 동작 | Billing 이용권 조회 |
| --- | --- |
| 첫 무료 세트 | 없음 |
| Part1 포함 유료 본문·모범답안·음성 제공 | 제공 요청마다 조회, 요청 간 캐시 없음 |
| 목록·진도·기존 결과·polling | 없음. 유료 원문을 섞어 제공하지 않음 |
| create·사용자 녹음 upload-url·submit | 없음. 신규 제출에도 유료권 조회하지 않음 |
| retry·채점 worker·completion | 없음. 기존 상태·소유권·중복 처리 검증은 유지 |

어떤 경로든 유료 본문/음성을 새로 제공하는 부분이 있다면 그 부분에는 검사를 적용한다. 사용자 음성 업로드 URL과 유료 모범답안 다운로드 URL은 구분한다.

## 2. 수용하는 위험과 유지하는 보호

- 본인 인증과 유효 문항 ID·제출 형식·음성 등 기존 조건을 충족한 사용자는 이용권 없이 직접 신규 제출/채점을 요청할 수 있다. 이전에 받은 콘텐츠 재사용도 이용권으로 차단하지 않는다.
- 따라서 이 정책은 콘텐츠 접근 유료화이지 채점 API의 유료권 보장이 아니다. ‘과거에 허용된 사용자만 제출할 수 있음’이라고 설명하지 않는다.
- 이 위험을 막기 위한 세트 시작 기록·승인 receipt·별도 토큰·create 권한 확인을 추가하지 않는다.
- 기존 인증·현재 소유권·삭제·탈퇴·문항 유효성·제출 상태/기간·멱등성·건별 재시도 제한을 유지한다. 콘텐츠만 검사한다는 이유로 기존 보안/lifecycle 검사를 제거하지 않는다.
- 학습 신규 생성 하루300회 및 실패 재시도 일일 차감 제외 계획은 유지한다. 이는 비용을 일부 제한할 뿐 유료권 검사를 대체하지 않는다. 모의고사는 변경하지 않는다.

## 3. 기존 계약과의 관계

review-2 원문 및 Billing snapshot의 bytes/hash는 보존한다. 기존 문서의 신규 submit 조회·queue 직전 Billing 유효시간 검사·접수 근거를 이용한 Billing 재조회 예외 설명은 이 보완 범위에서 대체한다. 기존 Job의 복구 가능 여부를 검증하는 상태/접수 근거는 그대로 유지한다.

유료 콘텐츠 조회의 route/audience·유료권 전용 판정·무차감·무캐시·16KiB·기존 오류 매핑 및 엄격한 wall/monotonic 시각 검증은 변경하지 않는다. validUntil 검사는 유료 콘텐츠 제공 결정 시 적용하며 submit 승인 기한으로 저장하거나 전달하지 않는다.

Billing endpoint 구현은 콘텐츠 요청용으로 동일 규격을 사용한다. 호출 범위 변경을 Billing에 보완 전달하고 확인받아야 하며 이 문서가 Billing 수락을 대신하지 않는다. 기존 재답변은 불변이다.

## 4. 대체 검증 명세

| ID | 검증 |
| --- | --- |
| C01 | Part1 포함 유료 상세/음성 요청에만 유료권 조회. 무료/목록/진도/결과 미호출 |
| C02 | create/upload/신규 submit/retry/completion/worker에서 Billing 미호출. 기존 입력·owner·상태 검증 유지 |
| C03 | 콘텐츠 허용 후 이용권 만료·환불 또는 Billing 장애가 생겨도 정상 제출 처리 가능. 새 유료 콘텐츠 요청은 별도로 조회 |
| C04 | 인증·문항·제출 등 기존 조건을 만족한 직접 신규 제출은 유료권 없이 가능함을 승인된 잔여 위험으로 검증. 무인증/타인 접근은 계속 거절 |
| C05 | 콘텐츠 조회에서 review-2 시간·strict 응답·401/402/503/500 및 원격 무차감 검증 유지 |
| C06 | 학습300회/재시도 제외 및 기존 Job 중복·삭제·탈퇴·모의고사 비영향 회귀 |

review-2 L02는 C02/C03/C04로 대체한다. L10의 freeze 후 Billing 실패 검증은 삭제하고 기존 파일/queue 실패와 중복 처리 회귀만 유지한다. L05의 신규 접수 직전 시각 검사는 콘텐츠 제공 결정 시 검사로 범위를 좁힌다. L11의 기존 상태/owner 보호는 유지하되 Billing 조회 우회 예외 판단을 위한 새 접수 증거 구조는 추가하지 않는다. 테스트는 아직 실행하지 않았다.

이번 작업은 문서 변경만 수행했다. 제품 코드·DB·환경·Billing 저장소·Jira·외부 전달·commit/push·배포 변경은 없다.
